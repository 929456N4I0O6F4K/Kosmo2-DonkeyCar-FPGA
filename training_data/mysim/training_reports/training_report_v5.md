## 0. 版本迭代总览：基线 → v1 → v2 → v3 → v4 → v5

**谱系：**六版共用同一模型架构（219,732 参数，§2）与同一批物理采集（physicaldata2，4717 行车帧），全部模型文件同名 `mypilot1_s2_physical_best.keras`，各版本权威配置记录在其 `train_config.json`。v1–v3 补齐了同帧 4717 帧评估（v1/v2 按 CLAHE 部署口径推理，v3–v5 为纯裁剪口径），因此本节首次给出**六版本同口径横比**；§1–§8 保持对 v4→v5 的深度展开。

| 版本               | 核心变更                                                                                                              | 动机与依据                                                                                       |
| ------------------ | --------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| **基线** physical2 | A+B+C+D 管道首训；不做角度平衡，保留真实分布（急右占 48.7%）                                                          | 建立物理域基线 + BRAM 优化架构锚点                                                               |

> **为什么 MAE 单调上升 ≠ 实车退步（本表最重要的解读）：**4717 帧是六版共用的训练池（in-sample），且评估标签是**未清洗的原始 user angle**。raw 口径下"对标签拟合得越死，MAE 越低"——基线在急右箱（48.7% 帧数）上拟合最充分，自然拿下最低 MAE；而 v3–v5 的过采样/欠转惩罚/标签清洗**故意不拟合**原始标签中的噪声（手柄抖动、反应延迟、修正帧），这些帧在 raw 口径全被计为"误差"。同理，v4 移除直行幅值惩罚、保留预判打角后，直行 |pred|>0.2 上升的部分是模型在直行段提前给弯道打角（对预判是正确行为，raw 口径计为误差）。**本表用于读"设计取舍的轨迹"，不能直接读"实车性能排序"**；实车排序要看 v1 诊断、清洗后验证集（§6/附录 A TTA 口径）与镜像等变性（§7）。

> **设计取舍的真实轨迹：**v1 用 3× 直行权重 + CLAHE 换来全谱系最稳的直行（|pred|>0.2 仅 16.2%、直行箱 MAE 0.108），代价是急弯欠转 28.5%；v2 的急弯 2× 权重 + 门控欠转惩罚把欠转率压到全谱系最低 21.1%、急弯 MAE 0.158，直行立刻回退到 28.8%——容量守恒，直行与急弯此消彼长；v3–v5 在部署一致化（去 CLAHE）+ 分布均衡 + 标签清洗上推进，急弯表现改用清洗后验证集与行为标记衡量（急弯 MAE 0.209→0.186、欠转 31.9%→25.6%，§6）。另注意：各版本 `evaluation_tta`（v1 0.169 / v2 0.173 / v3 0.171 / v4 0.188 / v5 0.194）是**各自验证集**上的成绩，清洗前后难度不同，不可横比——本表才是同口径。

> **恒定难点——中左箱：**基线/v1/v2 的中左箱（|t|∈[−0.5,−0.2)，n=349）MAE 分别为 0.319 / 0.319 / 0.315，六版谱系中**最难箱恒定不变**：样本最少、且混有大量入弯过渡段（标签介于小左与急左之间）。v3 已将其过采样目标提到 1200 帧，但 raw 口径下 v3+ 无法读箱指标（清洗改变了该箱标签），此箱的量化验证留给 v6。

## 1. 数据管道：从行车记录到可训练样本

1. **① 采集**：6 sessions 共 5673 帧（含 physicdata 直行补充 964 帧）
2. **② τ 时间对齐**：参考模型扫 τ∈[−3,+3] 帧，对齐反应延迟
3. **③ 中值滤波**：窗口 5，抹平 1–2 帧手柄抖动，保留 ≥3 帧预判
4. **④ 剔修正帧**：2 帧内反向跳变 |Δa|>0.3 的毒样本剔除
5. **⑤ 时间留出**：按时间切 15% 验证集，防泄漏
6. **⑥ 分箱过采样**：仅训练集，按目标箱数均衡
7. **⑦ 在线增强**：23 项增强 + 成对镜像 + Mixup

| 来源                | 帧数              | 说明                                    |

| 主赛道 session      | 4523              | 连续行车录制                            |

| ---- | ---- | ---- | ---- | ---- | ---- | ---- |
| 453  | 336  | 503  | 996  | 540  | 534  | 2311 |

### 1.2 清洗三件套的实现细节

**τ 时间对齐：**司机看到弯道后隔 1–2 帧才打角（反应延迟），出弯回正同样滞后。实现上用 opt3 最佳模型作为参考，对每个 session 做预测序列 vs 标签序列的 τ∈[−3,+3] 帧扫描（|τ|<3 且 session≥40 帧才处理），仅当 MAE 改善超过 2% 才应用平移，否则 τ=0 不动。关键设计：**预判性提前打角不会被删除**——对齐只是把标签移到与图像视觉事件正确的对应帧上。

**中值滤波（窗口 5）：**手柄抖动是孤立的 1–2 帧尖峰，被中值抹掉；预判性提前打角持续 ≥3 帧，中值保边，完整保留。这同时满足「去抖」与「保留直行段预判意图」（v4 起用户确认预判打角是真实驾驶意图，不作为不稳定因素惩罚）。

**剔修正帧：**打角过冲后 1 帧内急速反向拉回的帧是「毒样本」（图像还没变，标签却反向跳变）。实现为逐帧检测：|a[i]−a[i−1]| > 0.3 且 |a[i+1]−a[i]| > 0.3 且两次跳变方向相反 → 剔除帧 i。渐进预判打角与弯道入口快速打角均为同向渐变，不会误剔。

### 1.3 分箱均衡过采样

仅作用于**训练集**（验证集保持真实分布，避免评估失真）。重复帧每个 epoch 会经历不同的随机增强，等价于「廉价的新样本」。

## 2. 模型架构与 FPGA 部署约束（不可变项）

本次训练的**硬约束**是：架构必须保持方案2 不变，即 Conv5 输出通道收窄为 16、输入为裁剪后的 95×156 图像。它由紫光 PG2K100 的 BRAM 预算倒推得出：

| 层       | 配置                  | 输出          | BRAM(块)              |
| -------- | --------------------- | ------------- | --------------------- |
| Conv1    | 3→24, 5×5, s2         | 46×76×24      | 1                     |
| Conv2    | 24→32, 5×5, s2        | 21×36×32      | 5                     |
| Conv3    | 32→64, 5×5, s2        | 9×16×64       | 12                    |
| Conv4    | 64→64, 3×3, s1        | 7×14×64       | 8                     |
| Conv5    | 64→16, 3×3, s1        | 5×12×16       | 2                     |
| Flatten  | 960                   | —             | —                     |
| Dense1   | 960→100               | 100           | 21                    |
| Dense2   | 100→50                | 50            | 2                     |
| Dense3   | 50→2 (angle,throttle) | 2             | 1                     |
| **合计** | 219,732 参数          | 231.1 KB INT8 | **52 / 144（36.1%）** |

- 原版 Donkey 模型（Dense1 960→100 展开）INT8 体积 816 KB → 需 **182 块 BRAM（126%，FAIL）**，根本放不下。
- 真裁剪 95×156（传感器 ROI 而非缩放）+ 三级 stride-2 下采样 → Flatten 输入从 9600 降到 **960**，Dense1 参数 665,600 → 96,000（**21 块 BRAM，单块利用率 99.2%**，恰好是 BRAM 拼切的最优点）。
- Conv5 通道 64→16：最后一级特征图已 5×12，64 通道信息冗余，收窄省 3 块 BRAM 且整卷实测精度损失可接受。
- 全模型约 1.02M MAC/帧 —— 瓶颈在**存储**不在算力，因此一切优化围绕「减权重、减激活、保精度」。
- 剩余 92 块 BRAM 留给流水线 line buffer，支持 ap_fixed<8,1> 全 INT8 数据流。

> 训练侧所有技巧（损失加权、增强、过采样、Mixup、SWA、双 trial）都是在**不动架构一个参数**的前提下榨精度的手段——这就是「架构不可变」的含义。

## 3. 损失函数：WeightedMSE 的精确实现

标准 MSE 对所有样本一视同仁，但驾驶任务里误差的**代价不对称**：大弯欠转意味着冲出赛道（高风险），直行小抖动几乎无害（低风险）。WeightedMSE 从两个维度注入这种先验：

### 3.1 分箱权重（代价敏感加权）

| 分箱         | 急左 | 中左 | 小左 | 直行 | 小右 | 中右 | 急右 |
| ------------ | ---- | ---- | ---- | ---- | ---- | ---- | ---- |
| angle 项权重 | 2.0  | 1.5  | 1.0  | 2.0  | 1.0  | 1.0  | 1.5  |

> 急左/直行/急右 ×2.0，中左/中右 ×1.5：急弯是安全底线，直行 ×2.0 用于压住「直行段乱打角」（漂移是实车最容易翻车出界的状态）。throttle 项不加权。

### 3.2 门控欠转惩罚（条件加倍）

```
under_mask = (|y_true[:,0]| > 0.3) & (|y_pred[:,0]| < |y_true[:,0]|)   # 真值大弯 且 预测幅值不足
angle_sq   = where(under_mask, angle_sq * 2.0, angle_sq)                # 仅对欠转样本再 ×2
weighted   = stack([angle_sq * bin_weights, y_sq[:,1]])                 # 分箱权重只作用于 angle
loss       = mean(weighted)                                             # WeightedMSE(t, p)
```

> 门控设计的意义：欠转惩罚**只在大弯且预测偏小时触发**，不会把模型推向「处处过转」；与直行 ×2.0 权重组合后，形成「直行要稳、大弯要足」的双端约束。

> **诚实声明：**train_config 中存在 `LABEL_SMOOTHING = 0.05`，但 grep 全脚本确认它**未接入损失或管道**（仅定义 + 写入配置），对 v5 训练无实际影响，本报告不将其计入有效优化项。

## 4. 训练策略与导出

|                |                                                    |
| -------------- | -------------------------------------------------- |
| 初始化         | 迁移自 mypilot1_s2_cropped.keras（方案2 原始权重） |
| 优化器         | Adam，LR 3e-4 → 1e-6                               |
| 调度           | warmup 3 epochs → cosine 退火                      |
| batch / epochs | 64 / 最多 100，EarlyStopping=15（val_loss）        |
| 验证集         | 时间留出 15%（同 session 不跨集合，防时间泄漏）    |
| Mixup          | α=0.2，p=0.2（20% 批内样本线性插值）               |
| SWA            | 随机权重平均（C_swa=0.75）                         |
| TTA            | [原图, 水平翻转]（导出评估用）                     |
| 种子 / Trial   | seed 42 / 142 双 trial 独立训练                    |

- **时间留出：**行车数据强时间相关，随机划分会让验证集「见过」训练段前后帧，虚高成绩；按时间切尾段 15% 强制考验 unseen 路况。
- **warmup-cosine：**迁移学习起步用大 LR 会破坏预训练低层特征，3 epoch 线性爬升保护之；cosine 后段自动细调。
- **Mixup：**对「图像↔角度」做凸组合正则，抑制对单帧纹理的记忆，平滑决策面。
- **SWA：**对损失面平坦区取权重平均，提升量化友好度（平坦极小值对 INT8 扰动更鲁棒）。
- **双 trial 选优：**小数据 + 大增强下，随机种子方差不可忽略。两 trial 的 val_loss 差 2.8%（0.073194 vs 0.075255），选优是免费收益。

| **A_basic 基础几何/光度**                 | 水平翻转**禁用**（由成对镜像替代）；亮度 ±80；对比度 0.5–1.6；旋转 ±10°；横移 ±15 px；纵移 ±5 px                                                              | 相机安装偏差、车道偏移视角                      |

## 7. 镜像等变性专题：v5 最重要的短板

**为什么测它：**赛道可以反向跑。一个方向上训练的模型，把图像水平翻转后输入，预测应等变于标签取反（flip 后的急右帧，模型应给出 ≈ −t 的强左转）。这不需要反向赛道数据就能离线量化「换向鲁棒性」。

| 指标           | 定义                                    | v4    | v5        | 变化    |
| -------------- | --------------------------------------- | ----- | --------- | ------- |
| 原方向到位率   | \|pred − t\| ≤ 0.2 的帧占比（直接输入） | 58.3% | **67.7%** | +9.4pt  |
| 翻转方向到位率 | \|pred_flip − (−t)\| ≤ 0.2（翻转输入）  | 43.9% | **11.5%** | −32.4pt |
| flip MAE       | \|pred_flip − (−t)\| 均值               | 0.295 | 0.481     | +63%    |
| mirror MAE     | \|pred_orig + pred_flip\|（应 ≈ 0）     | 0.514 | 0.521     | +1.5%   |
| 等变相关       | corr(pred_orig, −pred_flip)             | 0.337 | 0.308     | −0.03   |
| TTA MAE        | \|(p_orig − p_flip)/2 − t\| 均值        | 0.310 | 0.313     | +1.0%   |
| 失配帧(@0.5)   | \|p_orig + p_flip\| > 0.5 帧数（全量）  | 2198  | 2149      | −49     |

![镜像等变性对比](assets/fig8_fig_mirror.png)

*图 8 · 镜像等变性核心指标。左：到位率对比——原方向大涨、翻转方向崩塌；右：flip MAE 与等变相关。*

> **回退的机理解释（为什么会这样）：**v5 用「确定性成对镜像」把每帧与其翻转版**固定绑定**地反复成对喂入。模型很快学到在成对约束下输出平均化的对称行为（原方向急弯表现因此提升），但确定性配对使**每张翻转图的伴生上下文永远相同**——模型实际上仍以原始方向数据的纹理分布为主导记忆翻转样本，翻转分支从未被独立、多样地检验过；急右数据本就占 40%，翻转侧（等价于急左急弯）的有效多样性反而被压缩。结果是「成对约束拉平了统计量，却没有换来真正的等变表征」。这也解释了为何 mirror MAE 与 mismatch 几乎没变（对称性统计被配对平均修复了），而单侧 flip 行为崩塌（等变性本质没有学到）。

## 8. 优化思路与鲁棒性机理总结

下表把 v5 的每一项优化放回「它对抗哪种失效模式、靠什么机制、证据是什么」的框架里——鲁棒性提升的本质是**让训练分布覆盖并超越推理时可能遇到的失效面**。

| 优化项                        | 对抗的失效模式                     | 机制                                      | 证据（v4→v5）                                     |
| ----------------------------- | ---------------------------------- | ----------------------------------------- | ------------------------------------------------- |
| τ 时间对齐                    | 标签滞后：图像已入弯，标签还是直行 | 参考模型扫 τ，把标签平移到视觉事件帧      | 整圈 MAE −3.4% 的基础贡献之一                     |
| 中值滤波(5) + 剔修正帧        | 手柄抖动尖峰、过冲后急回的毒样本   | 保边滤波；2 帧反向跳变检测剔除            | 反向 flag 仅 192→217（控制住了毒样本基数）        |
| 直行补充 964 帧 + 直行权重 ×2 | 直行漂移、蛇形                     | 补数据 + 损失双端约束「直行要稳」         | 直行预判占比稳定；直行 MAE +5.7%（见短板②）       |
| 分箱均衡过采样                | 急右 40% 占比淹没其他分箱          | 训练集过采样至目标箱数，验证集保真        | 小左 −3.9%、中左 −3.0%                            |
| 门控欠转惩罚 ×2               | 大弯转向不足 → 冲出赛道            | \|t\|>0.3 且 \|p\|<\|t\| 时 angle 项再 ×2 | 欠转帧 −20.4%；急弯 MAE −9.1%；极限弯 −13.4%      |
| 成对镜像 ×2                   | 左右方向偏置                       | 同 batch 翻转约束，标签取反               | 原方向到位率 +9.4pt；**翻转方向 −32.4pt（回退）** |
| 干扰线 25% / 淡线 30%         | 邻道误导、标线褪色                 | 场景级合成（仅急弯帧叠加干扰线）          | 反向 flag 增幅被控制在 +25 帧                     |
| 运动模糊 / cutout / 阴影 / γ  | 震动糊帧、遮挡出画、光照突变       | 物理成因对齐的增强族                      | 整圈 corr 0.882→0.886 稳中有升                    |
| Mixup + SWA + 双 trial        | 过拟合、极小值尖锐化、种子敏感     | 插值正则 + 平坦权重平均 + 选优            | T2 vs T1 val_loss 差 2.8%，选优即收益             |
| INT8 PTQ + 导出 TTA 校验      | 量化误差、导出链路失配             | 对称量化 + [orig, flip] TTA 复评把关      | INT8 评估 MAE 0.19369 / corr 0.89192              |

> **鲁棒性设计的两条主线：**(1) **数据侧**——清洗保证「标签说的是图像里的事」，增强与过采样保证「训练分布 ≥ 推理分布的失效面」；(2) **目标函数侧**——把驾驶风险（欠转出界）与稳定性（直行不漂）写成可优化的加权项，而不是靠网络自己悟。所有这些都在 219K 参数、52 块 BRAM 的固定预算内完成，属于「约束下的精度榨取」。

## 附录 C · 鲁棒性增强方法（v5）

本附录对应训练脚本 `scripts/train/train_s2_physical2_opt5.py` 的 `augment_image_enhanced()`：逐项强制触发单一增强（其余项关闭），参数取 uniform 分布的 75% 分位以便观察，因此单强项预览 = 训练时真实像素处理结果，不是示意图。

### C.1 设计原则

- **训练分布 ≥ 推理分布的失效面**：每一项增强对应一种在实车上真实出现过、但训练集里样本不足的成像退化，不是无目的随机扰动。
- **物理成因对齐**：模糊来自线核卷积、白斑来自椭圆高斯、形变来自正弦/透视映射、干扰线来自真实线条绘制，避免「像素乱抖」式的伪增强。
- **不破坏标签语义**：几何增强只改变视点不改变转向意图；裁剪与翻转的改写规则在代码中与标签同步维护（翻转时 `angle → −angle`）。
- **分组管理**：A_basic（几何/光度）、A_light_robust（光照与成像退化）、帆布场地特异、scene_distract_v5（场景干扰）、成对镜像，共 23 项 + 1 个配对机制。

### C.3 像素级处理要点

- **几何族（#1/#4/#5/#6/#13）**：全部走仿射矩阵 + `warpAffine`，边界填充统一为反射（平移）或灰 128（旋转/抖动），避免 v4 之前 `np.roll` 的环绕卷绕伪影；翻转同步改写角度标签。
- **光度族（#2/#3/#8/#15/#16）**：加性偏移与乘性增益严格区分——亮度是加、对比度/曝光/色温是乘，gamma 走 256 项 LUT，保证与相机 ISP 的真实响应顺序一致。
- **噪声与模糊族（#9/#11/#14）**：线核按角度逐点连线后归一化（和为 1），不做模糊方向外的能量丢失；σ 上限 15 对应低照度噪声实测水平。
- **遮挡族（#10/#12/#21）**：阴影是乘性遮罩、cutout 是硬填 128、灯光带是加性向白饱和，三种遮挡的物理机制不同，分别覆盖「变暗」「无信息」「过曝丢失」。
- **场地特异族（#17/#18/#19/#20/#21）**：全部针对帆布赛道——反光白斑、褪色、褶皱形变、透视收敛、高光带，是这套数据里最容易让模型「看不见线」的五种情形。
- **场景干扰族（#22/#23）**：干扰线带门控（仅 `|angle|>0.3` 触发，直行帧不叠加，否则会教模型在直道乱打角）；淡线用 HSV 阈值锁定近白像素，只压暗标线不动背景。
- **成对镜像（M）**：确定性翻转 + 标签取反 + 关闭随机翻转，构成严格的等变样本对；但 §7 已实测该策略导致单侧等变性回退，属于已知短板。
