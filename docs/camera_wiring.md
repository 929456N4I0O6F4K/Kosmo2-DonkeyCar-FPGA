# Kosmo2 J8 与 OV2640 DVP 接线规划

状态：**本表接线已通过 2026-10-01 独立 camera 实板验收**：ID 0x2642、初始化及成像正常；952 秒监测中 14,286 帧、0 个结构异常，见[验收报告](../camera/docs/acceptance_20261001.md)。该次台架采用 FPGA 内部弱上拉及 10 kHz SCCB。OV2640 排针文字来自 [用户记录](../引脚信息.md)，模组 P0 对应 PWDN，详见[模组资料核对](../camera/docs/module_reference.md)。J8 针号与封装脚来自 `赛题相关数据kosmo/Kosmo硬件手册.pdf` 第 18–19 页。两块排针都按用户记录的视角、从左到右读取；Kosmo2 图中的上排是 J8 偶数脚（2, 4, ..., 40），下排是奇数脚（1, 3, ..., 39）。**不要将两块双排针直接对插。**

## 相机逐线接法

2026-10-14 已核对用户补充的 OV2640 转接板顶层、底层图：H1 相机接口及 H2 PCA 接口的走线与本表一致，详见[转接板与排线核对](../camera/docs/adapter_review_20261014.md)。H1 针号与厂商相机 P1 针号不同，使用排线时须按该文的信号对应关系确认端点。PCB 图像核对不能替代实板通断测量。随后将整机相机 SCL 改为推挽驱动、SDA 保持开漏，替换 OV2640 已恢复初始化和清晰实景；v7 一键部署通过，见[最新恢复记录](../camera/docs/recovery_20261014.md)。下文 2026-10-01 的内部弱上拉验收属于历史台架配置。

**2026-10-01 针号勘误：PCLK 应接 J8-10 / Y7；J8-9 是 GND。**此前把 Y7 的连接器针号写成 9，是接线说明错误。已对照[硬件手册](../../赛题相关数据kosmo/Kosmo硬件手册.pdf) PDF 第 18–19 页逐项复核本表；[第 18 页图像](../camera/build/j8_manual_page_18.png)明确列出 9→GND、10→Y7。FPGA 约束的 `cam_pclk Y7` 本身正确，PDS 引脚/时序通过不等于连接器针号或实物接线正确。若 PCLK 接到了 J8-9，先断电，再移到 J8-10。

纠正 PCLK 时的核对结果保存在[针号复核记录](../camera/build/j8_pin_review.json)：包含 PDF 提取的全部 40 个针位和当时 23 项连接。本轮根据相机资料把 P0 从原预留 J8-7/Y18 改为 J8-9/GND，以本表及[模组资料核对](../camera/docs/module_reference.md)为准。

相机的“上/下排第 N 位”只用于消除同名针脚方向歧义。接线时仍须以模组丝印、板卡 J8 的 pin 1 方焊盘或原理图确认方向。

资料包中旧版 ATK-OV2640 V1.2 自带 **12 MHz** 有源晶振，新版 V2.2 为 **24 MHz**，两版均无需 FPGA 输出 XCLK。用户记录含 NC，与旧版一致；实板晶振型号尚未直接核实。当前数字计数测得 PCLK 平均约 1.500025 MHz、帧率 15.0063 Hz，160×120 RGB565 输出已验证；这些结果不替代晶振或模拟波形测量。

**断电后将 P0/PWDN 接 J8-9/GND。**两版原理图都将该脚直连传感器，未绘制外部下拉。此前“暂不接”是功能未确认时的临时措施，现已由厂商资料确定接法。当前 RTL 未驱动 J8-7/Y18，不使用该预留脚。

**标准外部上拉接法：SDA 和 SCL 各一只 4.7 kΩ 至 3.3 V。**两版模组原理图都没有板载 SCCB 上拉；若连接线/转接板尚未提供，在 SDA（J8-33）和 SCL（J8-35）上分别增加上拉，两线仍分别连 FPGA。电阻接成支路，不能串入信号线或用导线直接上拉。模组用户手册确认其 2.8 V IO 兼容 3.3 V 系统；不要按裸片供电参数混接电源。来源、页码及版本差异见[模组资料核对](../camera/docs/module_reference.md)。当前无外部电阻的台架使用下述已验证配置。

2026-10-01 台架补充：用户没有外部电阻，相机端两线在无内部上拉时均为 0.44 V，启用 FPGA 内部弱上拉后均升至 3.3 V。万用表固定电平又定位了 SDA/SCL 互换；纠正为 SDA→J8-33、SCL→J8-35 后，`camera_jtag` 的内部弱上拉、10 kHz 配置通过初始化和完整台架验收。内部上拉阻值及动态上升时间尚未实测，标准外部 4.7 kΩ 接法仍保留；UART 版仍需外部上拉。详情见[万用表测试](../camera/docs/meter_test.md)。

## UART 与 PCA9685 四线接口

| 用途 | J8 针号 | PG2K100 脚 | 处理方式 |
| --- | ---: | --- | --- |
| 原 `mypilot` PA UART RX | 3 | T20 | 保留现有 3.3 V USB-UART 调试接线 |
| 原 `mypilot` PA UART TX | 5 | U20 | 保留现有 3.3 V USB-UART 调试接线 |
| PCA9685 VCC | 1 | 板载 3.3 V 电源 | 控制板逻辑电源；核对 3.3 V 电源余量和控制板丝印 |
| PCA9685 I2C SCL | 37 | V10 | PA 驱动的 I2C 时钟 |
| PCA9685 I2C SDA | 38 | U9 | PA 驱动的 I2C 双向数据 |
| PCA9685 GND | 39 | GND | 与 Kosmo2 共地 |

J8-37/38 默认作为 **PA 侧 I2C 主机**；PU Linux 的 DonkeyCar 将来发送目标转向给 PA，再由 PA 驱动 PCA9685 产生舵机 PWM。它们不是 PU Linux 当前已映射的 I2C 控制器，现有 DonkeyCar PCA9685 驱动不能直接打开这两根线，后续需要 PU/PA 命令接口和 PA I2C 驱动。I2C 的 SDA 是双向开漏线，SCL 也按开漏设计；接入时上拉到双方兼容且经实物核实的 IO 电压，不能用推挽高电平或 5 V 上拉。

**电源分开：**12 V 锂电池接 Kosmo2 的主电源输入，不接 J8 或 PCA9685 `VCC`。Kosmo2 板载 3.3 V 从 J8-1 供 PCA9685 逻辑侧；相机从 J8-17 取同一板载 3.3 V。接入前核对锂电池满电电压、板卡主电源输入范围/极性、3.3 V 余量和 PCA9685 板上 I2C 上拉电压。PCA9685 芯片 VDD 额定范围为 2.3–5.5 V。

2026-10-04 用户补充：动力电池同时供电机和舵机，电调是好盈 WP-1625；PCA9685 没有另接独立电源，整套系统此前在树莓派上验证过。电调三线接口的 BEC 是否经 PCA9685 电源排给舵机供电，仍须实物核对；旧记录的“动力电池只供电机”不再作为当前事实。动力电池原始电压不能直接接逻辑 `VCC` 或 J8，也不能在未确认额定电压时直接接舵机 `V+`。PCA9685 的 `VCC` 仅为逻辑电源。Kosmo2 与 PCA9685 经 J8-39 共地；电机大电流不得经 J8 返回。

本版按你指定的四线接口连接，不接 OE。后续实车控制必须验证 PU/PA 命令超时后如何撤销舵机 PWM；仅停止发送 I2C 命令不会自动清除 PCA9685 已设定的输出。PCA9685 芯片供电范围见 [NXP 数据手册](https://www.nxp.com/docs/en/data-sheet/PCA9685.pdf)，`VCC`/`V+` 分离示例见 [Adafruit 控制板接线说明](https://learn.adafruit.com/16-channel-pwm-servo-driver/hooking-it-up)；后者不能替代你这块控制板的规格。

2026-10-04 已准备 [PCA9685 独立台架工程](../actuators/README.md)，默认全部关闭，提供配置读回和单通道限时测试；已完成仿真和构建。它尚未接入 PU 网页驾驶，也不能在 I²C 断线或 PA 停止运行时保证关闭独立供电的 PCA9685。

相机 `SDA/SCL` 与舵机控制板 `I2C_SDA/I2C_SCL` 是两组不同线。J8-7 的 Y18 也在 PMOD0 上出现，J8-3/5 的 T20/U20 同样与 PMOD0 共脚；使用此方案时，PMOD0 上这些位置不能再接另一设备。PMOD1 属于不同电压域，本方案不使用。

## 上电前检查

1. 对照模块 P1 方向确认 `P0/PWDN` 接地、RST 接 FPGA 低有效复位输出；检查 PCB 型号/晶振标记，以区分旧版 12 MHz 与新版 24 MHz。模块电源输入为 3.3 V。
2. 对照板卡 PCB 版本/原理图和 PDS I/O 报告确认 J8 所用 Bank 的 VCCIO；PCLK 使用 **J8-10/Y7**，已按旧表接 J8-8/Y6 时需断电改线。camera 工程按本地原理图第 5 页将相机 L6、UART R5 设为 3.3 V，将 LED/拨码 R4 设为 2.5 V；仍须核对实板版本。
3. 断电接线，先接 GND 和信号，最后接 3V3；J8 的 pin 2/4 是 **5 V**，相机不能误接。
4. 标准接法为 SDA/SCL 分别通过 4.7 kΩ 上拉到 3.3 V；当前 JTAG 台架也可使用已验收的内部弱上拉、10 kHz 配置。若转接板已有上拉，先核实阻值与电压，避免重复添加。RST 由 FPGA 控制，P0/PWDN 接地。
5. 相机先验证供电、晶振、SCCB 应答，再验证 PCLK/VS/HREF/D[7:0]，最后采单帧。PCA9685 四线和底盘动力系统分别验收；当前相机阶段不接动力电池。

首轮采集同时保存原始字节与初始化配置，确认输出格式、字节顺序、行宽、帧高、帧序号及坏帧数量；再接入 `mypilot` 的 RGB 输入与 DonkeyCar 数据记录。
